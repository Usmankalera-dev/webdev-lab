# WebDev Lab
Interactive site that teaches HTML, CSS and JavaScript by building real things.
Loops 1–4 (Weeks 1–4) of the Spiral-model plan — see ../PLAN.md for the full plan. v1.0 — full course, quizzes, editor, certificates, search.
Static site: no backend, no build step, no external libraries or images.
Pages: index.html, lessons.html, enroll.html, unlock.html, dashboard.html, certificate.html, editor.html, lessons/html-1 to html-5, css-1 to css-5, js-1 to js-8, proj-1 to proj-5.
Run locally: python3 -m http.server 8000
Then open: http://localhost:8000
Progress, waitlist and enrollments are saved in the browser (localStorage).
