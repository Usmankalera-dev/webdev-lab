# WebDev Lab
Interactive site that teaches HTML, CSS and JavaScript by building real things.
Loop 1 (Week 1) of the Spiral-model plan — see ../PLAN.md for the full plan.
Static site: no backend, no build step, no external libraries or images.
Pages: index.html (sales page), lessons.html (23 lessons), lessons/html-1 to html-3 (free preview lessons).
Run locally: python3 -m http.server 8000
Then open: http://localhost:8000
Progress and waitlist entries are saved in the browser (localStorage).
