What is a function?

A function is a named block of code that does one job — and you can run it as many times as you like. Instead of writing the same five lines every time you need a total, you write them once inside a function, give it a name, and call it whenever you need it:

function greet() {
  console.log("Hello, welcome to WebDev Lab!");
}

greet();  // runs the function
greet();  // runs it again

Functions are the single most important idea in programming. They keep your code short, they give a name to a job so the code reads like a story, and when something is wrong, there is exactly one place to fix it.

Parameters and return values

Most functions need input. A parameter is a placeholder in the function's definition — a name for the value it will receive. An argument is the actual value you pass when you call it:

function add(a, b) {
  return a + b;
}

let result = add(3, 4);  // result is 7

Here a and b are parameters, and 3 and 4 are arguments. The return statement sends a value back to the caller and ends the function — nothing after a return runs. A function without return still runs its code, but it gives back undefined.

A function can take any number of parameters, and a parameter can have a default value that applies when the caller leaves it out:

function greet(name = "friend") {
  return "Hello, " + name + "!";
}
greet("Usman");  // "Hello, Usman!"
greet();         // "Hello, friend!"

Calling functions

Calling a function is just writing its name followed by parentheses. The value it returns can be stored in a variable, printed, or passed into another function — functions are values too, in the sense that their results are values you can use anywhere:

function square(n) {
  return n * n;
}

let area = square(5);       // 25
console.log(square(area));  // 625

Be careful with one common mistake: greet without parentheses is the function itself, while greet() with parentheses runs it. When you hand a function to an event listener (next lesson), you pass it without parentheses — button.addEventListener("click", greet) — because you want the browser to call it later, not right now.

Arrow functions

There is a shorter way to write a function, called an arrow function. It does the same job with less typing, and you will see it everywhere in modern code:

const add = (a, b) => {
  return a + b;
};

const double = (n) => n * 2;  // one line: return is implied

When an arrow function has only one line, you can drop the curly braces and the return — the value is returned automatically. Arrow functions are especially common for short jobs passed to other functions, like event listeners and array methods. Use the normal function style while you are learning, and switch to arrows when they feel natural.
