What is Flexbox?

Before Flexbox, laying out a row of boxes in CSS was painful — floats, hacks, and crossed fingers. Flexbox is the modern answer. It is a one-dimensional layout system: it arranges items in a row or a column, and it handles the spacing and alignment for you.

To use it, you set display: flex on a parent element. That parent becomes the flex container, and its direct children become flex items. The items line up in a row by default, and they shrink or grow to fit:

.row {
  display: flex;
}
.row div {
  background: #fef3c7;
  border: 1px solid #d97706;
  padding: 16px;
}

With those few lines, three divs sit side by side in a neat row. No floats, no widths to calculate. If you add a fourth div, it joins the row automatically.

Direction: row or column

The flex-direction property sets the direction of the main axis. row is the default — items go left to right. column stacks them top to bottom:

.row    { display: flex; flex-direction: row; }
.column { display: flex; flex-direction: column; }

You can also reverse either direction with row-reverse or column-reverse. The direction matters because it decides what the next two properties mean: justify-content always works along the main axis (the direction you chose), and align-items works along the other axis.

Aligning items

justify-content spreads items along the main axis. The values you will use most are flex-start (items at the start), center, flex-end, space-between (first item at the start, last at the end, space spread evenly between) and space-around:

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

align-items aligns items along the other axis — for a row, that means vertically. center is the famous one: it vertically centres items, which used to be one of the hardest things in CSS. And gap puts a fixed space between items, so you no longer need margins on every child:

.menu {
  display: flex;
  gap: 16px;
  align-items: center;
}

If the items do not fit, they shrink by default. Add flex-wrap: wrap and they move onto a new line instead of squeezing — useful for a grid of cards on a small phone screen.

A navbar with Flexbox

Here is the pattern behind almost every website header: a logo on the left, links on the right, everything vertically centred. Three rules do the whole job:

<header class="navbar">
  <a class="logo" href="#">My Site</a>
  <nav>
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
  </nav>
</header>
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 12px 20px;
  background: #111827;
}
.navbar a { color: white; text-decoration: none; }
.navbar nav { display: flex; gap: 16px; }

The header is a flex container, so the logo and the nav sit at opposite ends. The nav is itself a flex container, so its links sit in a row with a 16px gap. Nested flex containers like this are how real layouts are built — small rows inside bigger rows. You will use exactly this pattern in Mini Project 3.

Exercise — A row of three cards

Make a page with three cards (each a div with a heading and a sentence). Put them inside a container with display: flex and a 16px gap. Then try: change justify-content to center, then to space-between, and watch the cards move. Finally, add flex-wrap: wrap and shrink your browser window — the cards should drop onto a new line instead of squeezing.
