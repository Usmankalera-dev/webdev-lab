What is HTML?

HTML stands for HyperText Markup Language. It is the language that builds the structure of every web page. When you open a website, the browser reads the HTML file and turns it into the page you see — the headings, the text, the images, the buttons.

HTML is not a programming language like Python or JavaScript. You do not write logic or calculations in HTML. You write markup: you tell the browser what each piece of content is. This is a heading. This is a paragraph. This is a link. The browser then displays each piece in the right way.

Think of a web page like a house. HTML is the walls, the rooms and the doors — the structure. CSS is the paint and the furniture — the style. JavaScript is the electricity and the switches — the behaviour. In this course you learn all three, but we start with the structure, because nothing else works without it.

Tags and elements

HTML is written with tags. A tag is a word inside angle brackets, like <p>. Most tags come in pairs: an opening tag and a closing tag. The closing tag has a forward slash, like </p>. The text between the two tags is the content.

Together, the opening tag, the content and the closing tag form an element. Here is the simplest element in HTML — a paragraph:

<p>Hello, world!</p>

A few tags do not need a closing tag. They are called empty elements. The line break <br> and the image tag <img> are two examples. You will meet them in later lessons.

Tags can also carry extra information called attributes. An attribute sits inside the opening tag, like this: <a href="https://example.com">. The href attribute tells the link where to go. You will use attributes a lot, starting from Lesson 2.

The basic structure of a page

Every HTML page has the same skeleton. It looks small, but every website on the internet — from a personal blog to a big online store — starts from this shape:

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
    <p>This is my first web page.</p>
  </body>
</html>

Let us read it line by line. <!DOCTYPE html> tells the browser this is a modern HTML document. <html> is the root element — everything on the page lives inside it. The <head> holds information about the page that visitors do not see, like the page title shown in the browser tab. The <body> holds everything visitors do see: headings, text, images and links.

The <h1> tag is the main heading of the page. The <p> tag is a paragraph. That is all you need for your first page.

How the browser reads your page

When you open an HTML file in a browser, the browser reads it from top to bottom and builds the page. It ignores extra spaces and line breaks in your code, so you can format your code neatly without changing how the page looks. Indentation — the spaces at the start of a line — is for humans, not for the browser. Good indentation makes your code easy to read, so keep it tidy from day one.

One more thing: HTML is forgiving. If you forget a closing tag, the browser will usually guess what you meant and still show the page. Do not rely on this. Browsers guess differently, and a page that looks fine in Chrome can look broken in another browser. Close your tags, always.

Common beginner mistakes

  • Forgetting the closing tag, like writing <p> without </p>.
  • Mixing up the order of closing tags. Tags must close in reverse order: <p><strong>text</strong></p>, never <p><strong>text</p></strong>.
  • Putting visible content inside <head> instead of <body>. Nothing in the head shows on the page.
  • Using capital letters in tag names. HTML works with capitals, but the standard is lowercase — write <p>, not <P>.

Exercise — Build your first page

Open a text editor (Notepad on Windows, TextEdit on Mac, or VS Code if you have it). Type the full page from the example above, but change the heading to your name and the paragraph to one sentence about yourself. Save the file as my-first-page.html and open it in your browser. You just built your first web page — and that is exactly how every web developer started.
