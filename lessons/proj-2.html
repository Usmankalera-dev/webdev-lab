Mini Project 2: Contact Form

Every business website needs a way for visitors to get in touch. In this project you build a contact form that looks professional, checks its own inputs, and shows a success message without reloading the page — using everything from the HTML forms lesson and the JavaScript events lesson.

Step 1 — The HTML form

Start with the form from Lesson 4, inside a card. Every field has a label, a matching id, and the required attribute:

<form id="contactForm">
  <label for="cName">Your name</label>
  <input type="text" id="cName" required>

  <label for="cEmail">Email</label>
  <input type="email" id="cEmail" required>

  <label for="cMsg">Message</label>
  <textarea id="cMsg" rows="4" required></textarea>

  <button type="submit">Send message</button>
  <p id="formMsg"></p>
</form>

Step 2 — Style the fields

Form fields look plain by default. Give them full width, comfortable padding, a soft border, and a visible focus state so keyboard users can see where they are:

form { max-width: 480px; margin: 0 auto; }
label { display: block; font-weight: bold; margin: 12px 0 4px; }
input, textarea {
  width: 100%;
  padding: 12px;
  border: 1px solid #d1d5db;
  border-radius: 8px;
  font-size: 1rem;
}
input:focus, textarea:focus {
  outline: 2px solid #f59e0b;
  border-color: #f59e0b;
}

display: block on the labels puts each label on its own line above its field. width: 100% on the inputs makes them fill the form — remember box-sizing: border-box from the Box Model lesson, so the padding does not make them overflow.

Step 3 — Style the button

The submit button gets the amber style used across this site, full width so it is easy to tap on a phone:

button[type="submit"] {
  width: 100%;
  margin-top: 16px;
  padding: 12px;
  background: #f59e0b;
  border: none;
  border-radius: 8px;
  font-size: 1rem;
  font-weight: bold;
  cursor: pointer;
}
button[type="submit"]:hover { background: #d97706; }

Step 4 — Validate with JavaScript

The required attributes already stop empty submissions. Now add a JavaScript check of your own: on submit, stop the page from reloading with preventDefault(), and check that the message is at least 10 characters long:

let form = document.getElementById("contactForm");
let msg = document.getElementById("formMsg");

form.addEventListener("submit", function (e) {
  e.preventDefault();
  let text = document.getElementById("cMsg").value.trim();
  if (text.length < 10) {
    msg.textContent = "Please write a message of at least 10 characters.";
    msg.style.color = "red";
    return;
  }
  msg.textContent = "Thank you! Your message has been sent.";
  msg.style.color = "green";
  form.reset();
});

e.preventDefault() is the key line: without it, the browser would try to send the form and reload the page. With it, JavaScript stays in control. form.reset() clears all the fields after a successful send.

Step 5 — Test it

Open the page and try three things: submit it empty (the browser should point at the first empty field), submit it with a one-word message (your JavaScript error should appear), then submit it properly (the green success message should appear and the fields should clear). If all three work, your form behaves like a real one — the only missing piece is a server to receive the data, which is a later course.
