Four layers around every element

Every element on a web page is a box. Not a metaphor — a real rectangle, with four layers. From the inside out: the content (the text or image itself), the padding (space inside the box, between the content and the edge), the border (the line around the box), and the margin (space outside the box, between it and its neighbours).

Most layout problems in CSS are box model problems. An element looks too big? Probably padding. Two boxes touch each other? Probably a missing margin. Elements are different sizes even though you set the same width? Almost certainly the box model — and the fix is in the last section of this lesson.

Padding and margin

padding is the space inside the box. It takes the element's background colour with it — padding on a coloured button is coloured too. margin is the space outside the box. It is always transparent, and it pushes other elements away:

.card {
  padding: 20px;        /* 20px on all four sides */
  margin: 16px;         /* 16px gap around the card */
  background: #f3f4f6;
}

You can set each side separately — padding-top, padding-right, padding-bottom, padding-left — or use shorthand. With two values, the first is top and bottom, the second is left and right. With four values, the order is clockwise from the top: top, right, bottom, left. A handy way to remember it is "TRouBLe": Top, Right, Bottom, Left.

.box { padding: 10px 20px; }        /* 10px top/bottom, 20px left/right */
.box { margin: 8px 12px 8px 12px; }  /* top, right, bottom, left */

One quirk: vertical margins between two elements do not add up — they collapse into the larger one. Two paragraphs with margin: 20px have a 20px gap between them, not 40px. This is normal CSS behaviour, not a bug, and once you know it, it stops surprising you.

Borders

A border is the line around the padding. You set its width, style and colour, usually in one shorthand line:

.box {
  border: 2px solid #d97706;
  border-radius: 10px;
}

The style can be solid, dashed, dotted or none. border-radius rounds the corners — 10px gives soft corners, 50% turns a square into a circle, which is how round profile photos are made. Borders are also how you debug layout: give an element a bright red border and you can see exactly where its box is.

box-sizing: border-box

Here is the trap. By default, when you write width: 300px, the browser means "the content is 300px wide" — and then it adds the padding and border on top. A box with width: 300px and padding: 20px is actually 340px wide on screen. Two boxes that should fit side by side suddenly do not, and beginners spend hours wondering why.

The fix is one rule, and professionals put it at the top of every stylesheet:

* { box-sizing: border-box; }

With border-box, the width you set includes the padding and the border. A 300px box with 20px padding is 300px wide — the content area shrinks to fit. This website uses this rule, and so should you, in every project from now on.

One last useful trick: a block element with a fixed width and margin: 0 auto centres itself on the page. The left and right margins are set to auto, and the browser splits the leftover space equally:

.container {
  width: 90%;
  max-width: 800px;
  margin: 0 auto;
}

That is how this lesson page is centred — a container with a maximum width and automatic side margins.

Exercise — A card with the box model

Build a card: a div with a heading and a paragraph inside. Give it a light background, 20px padding, a 2px solid border, 12px rounded corners, and 16px margin. Then add box-sizing: border-box to your stylesheet, set the card width to 320px, and check that it stays 320px wide including its padding. Finally, centre the card with margin: 0 auto.
