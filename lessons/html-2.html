Lesson 2: Headings, Paragraphs & Links

Headings: h1 to h6

Headings organise your page the way chapter titles organise a book. HTML gives you six levels, from <h1> (the biggest, most important) to <h6> (the smallest). Browsers show them in decreasing size by default, but size is not their real job — their real job is meaning. Search engines and screen readers use headings to understand what your page is about.

<h1>My Travel Blog</h1>
<h2>Places I Visited in 2026</h2>
<h3>Lahore</h3>
<h3>Hunza</h3>
<h2>What I Packed</h2>

Notice the pattern: one <h1> for the whole page, then <h2> for the big sections, then <h3> for smaller parts inside those sections. Never skip levels — do not jump from <h1> straight to <h4> — and never use a heading only because you want big bold text. If something is not a heading, use a paragraph and style it with CSS later.

Paragraphs: the p tag

Most of the text on the internet lives inside <p> tags. A paragraph is a block of text, and the browser automatically adds space above and below it. One idea, one paragraph — that is the rule for readable writing on the web.

<p>HTML is the structure of every web page. It tells the
browser what each piece of content is: a heading, a
paragraph, an image, or a link.</p>

<p>This is a second paragraph. The browser puts space
between the two paragraphs, even though there is only
one blank line between them in the code.</p>

Inside a paragraph you can use small inline tags. <strong> makes text bold and important, <em> makes text emphasised (italic), and <br> forces a line break inside the same paragraph. Use <br> sparingly — for an address or a poem, not for spacing between paragraphs. That is what the paragraph tag is for.

Links: the a tag

The link is what makes the web a web. Without links, every page would be an island. The anchor tag <a> creates a link, and its href attribute says where the link goes:

<a href="https://example.com">Visit Example</a>

There are two kinds of links. An absolute link has the full address, starting with https://, and it can point to any website in the world. A relative link points to another page on your own site, using only the file path — no domain name needed:

<!-- Absolute link: goes to another website -->
<a href="https://www.wikipedia.org">Wikipedia</a>

<!-- Relative link: goes to a page on your own site -->
<a href="about.html">About Me</a>
<a href="lessons/html-1.html">Lesson 1</a>

Relative links are the right choice inside your own website, because they keep working even if your domain name changes. Absolute links are for other people's websites.

By default, a link opens in the same browser tab. If you link to another website, it is polite to open it in a new tab so your visitor does not lose your page. Add target="_blank" for that:

<a href="https://example.com" target="_blank">
  Open Example in a new tab
</a>

One last rule about links: the link text should say where the link goes. "Click here" tells the reader nothing. "Read Lesson 1" tells them everything. Good link text helps your readers, and it helps search engines understand your site too.

Linking to a part of the same page

Sometimes you want a link that jumps to a section on the same page — like a "Back to top" link, or a table of contents at the start of a long article. You do it in two steps. First, give the section an id attribute. An id is a unique name for one element on the page. Second, link to it with a hash (#) in front of the name:

<!-- Step 1: give the section an id -->
<h2 id="menu">Our Menu</h2>

<!-- Step 2: link to it with a hash -->
<a href="#menu">Jump to the menu</a>

When the reader clicks the link, the browser scrolls straight to the section with that id. The id must be unique — two elements on the same page must never share an id — and it cannot contain spaces, so use hyphens, like id="my-favourite-books". You will use ids again in the CSS and JavaScript modules, where they let you style and control one exact element.

Putting it together

Headings, paragraphs and links are the three tags you will use more than any others. A complete little page needs nothing else:

<h1>Ali's Bakery</h1>
<p>Fresh bread, cakes and biscuits, baked every morning
in Lahore.</p>

<h2>Our Menu</h2>
<p>See the full menu on our <a href="menu.html">menu
page</a>, or visit our <a href="https://instagram.com"
target="_blank">Instagram page</a> for daily photos.</p>

Exercise — A page about yourself

Open your my-first-page.html file from Lesson 1 and add: an <h1> with your name, an <h2> called "About Me", two paragraphs about yourself, an <h2> called "My Favourite Websites", and three links to real websites you like (open them in new tabs). Save and refresh your browser. You now have a real personal page with structure, text and links.
