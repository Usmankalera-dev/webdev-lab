Making decisions with if

Real programs make decisions. "If the password is correct, let the user in. Otherwise, show an error." In JavaScript, that is an if statement. The code inside the braces runs only when the condition is true:

let age = 20;
if (age >= 18) {
  console.log("You are an adult.");
} else {
  console.log("You are under 18.");
}

The condition uses comparison operators: === (equal), !== (not equal), >, <, >=, <=. Notice === has three equals signs. Two equals (==) also exists, but it converts types before comparing, so "5" == 5 is true while "5" === 5 is false. The three-equals version is stricter and safer — always use ===.

You can chain decisions with else if:

let marks = 85;
if (marks >= 90) {
  console.log("Grade: A+");
} else if (marks >= 80) {
  console.log("Grade: A");
} else if (marks >= 70) {
  console.log("Grade: B");
} else {
  console.log("Grade: C or below");
}

JavaScript checks the conditions from the top and runs the first one that is true, then skips the rest. Order matters: put the most specific condition first.

Combining conditions

Real decisions usually combine two or more checks. && means "and" — both sides must be true. || means "or" — at least one side must be true. ! means "not" — it flips true to false:

let age = 20;
let hasTicket = true;
if (age >= 18 && hasTicket) {
  console.log("You may enter.");
}
if (age < 18 || !hasTicket) {
  console.log("You may not enter.");
}

A common pattern is a guard: check the bad case first and stop early, so the rest of the function only runs when everything is fine. It keeps the code flat and readable instead of nesting ifs inside ifs.

Repeating with loops

A loop repeats code. The for loop is for when you know how many times to repeat. It has three parts, separated by semicolons: start, condition, and step:

for (let i = 1; i <= 5; i++) {
  console.log("Count: " + i);
}
// Count: 1, Count: 2, Count: 3, Count: 4, Count: 5

Read it as: start with i at 1; while i is 5 or less, run the code, then add 1 to i. The variable i is the counter — by tradition it is called i, short for index.

The while loop is for when you do not know how many times: it repeats while its condition is true, and stops when it becomes false. Be careful — if the condition never becomes false, the loop never stops, and the page freezes. Always make sure something inside the loop moves towards the exit:

let number = 1;
while (number < 100) {
  number = number * 2;
}
console.log(number);  // 128

Looping over things

Loops are most useful for going through a list. The for...of loop takes each item in turn, with no counting needed:

let fruits = ["apple", "banana", "mango"];
for (let fruit of fruits) {
  console.log("I like " + fruit);
}

You will use this pattern constantly in the next lesson, where lists become arrays, and in the final project, where a loop draws every task in the to-do list. Conditions decide whether code runs; loops decide how many times. Together they are the two ideas that make programs useful.

Exercise — A grading program
