Mini Project 4: Image Gallery

A photo gallery is a grid of images with captions — a photographer's portfolio, a shop's products, a travel blog's best shots. In this project you build one with CSS Grid, a layout system made for two-dimensional grids. The pictures here are coloured placeholder blocks: replace each one with your own photos, and the gallery is ready to show people.

Step 1 — The HTML: figures in a grid

Each picture is a <figure> with a coloured block standing in for a photo, and a <figcaption> underneath. Six of them go inside a gallery container:

<div class="gallery">
  <figure>
    <div class="photo" style="background: #f59e0b;">Hunza</div>
    <figcaption>Hunza valley in autumn</figcaption>
  </figure>
  <figure>
    <div class="photo" style="background: #3b82f6;">Sea</div>
    <figcaption>The sea at Clifton beach</figcaption>
  </figure>
  <!-- four more figures the same way -->
</div>

The style attribute here only sets the placeholder colour. When you use real photos, replace each <div class="photo"> with an <img> tag — the CSS below works for both.

Step 2 — CSS Grid layout

CSS Grid is like Flexbox, but for two dimensions at once — rows and columns together. display: grid turns the container into a grid, and grid-template-columns defines the columns. The magic value is repeat(auto-fill, minmax(200px, 1fr)): "make as many columns as fit, each at least 200px wide, sharing the space equally":

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}

On a laptop that gives three or four columns. On a phone it gives one or two — automatically, with no media query. 1fr means "one fraction of the free space", so the columns always share the width evenly.

Step 3 — Style the pictures and captions

Give each picture a fixed height and rounded corners, and centre the caption text underneath:

.photo {
  height: 160px;
  border-radius: 12px;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
  font-weight: bold;
  font-size: 1.2rem;
}
.gallery figcaption {
  text-align: center;
  margin-top: 8px;
  color: #4b5563;
}

For real photos, add width: 100%; height: 160px; object-fit: cover; to the img instead — the picture fills the box without stretching, exactly like the round profile photo in Project 1.

Step 4 — A hover effect

A small hover effect makes the gallery feel alive. When the mouse is over a figure, the picture lifts slightly and grows a soft shadow. The transition property makes the change smooth instead of instant:

.gallery figure { margin: 0; transition: transform 0.2s ease; }
.gallery figure:hover {
  transform: translateY(-4px);
}
.gallery figure:hover .photo {
  box-shadow: 0 8px 20px rgba(0, 0, 0, 0.2);
}

transform: translateY(-4px) moves the whole figure 4 pixels up. Transforms do not disturb the layout around them — the other pictures stay exactly where they are.

Step 5 — Responsive check

Shrink your browser window and watch the grid: columns should drop from four to three to two to one, with no horizontal scrolling and no squashed pictures. If a column looks too narrow on a phone, lower the minimum in minmax() from 200px to 150px. That one number controls the whole responsive behaviour — change it and the grid reflows itself.
