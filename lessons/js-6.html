Lists with arrays

A variable holds one value. An array holds a list of values, in order, inside square brackets. Each value has a position called an index — and the first position is 0, not 1:

let fruits = ["apple", "banana", "mango"];
console.log(fruits[0]);  // "apple"
console.log(fruits[2]);  // "mango"
console.log(fruits.length);  // 3

The length property tells you how many items there are. The last item is always at index length - 1 — for three items, index 2. Asking for an index that does not exist gives undefined, not an error, so check your indexes carefully.

You can change an item by its index, and you can loop over the whole list with the for...of loop from the last lesson:

fruits[1] = "orange";
for (let fruit of fruits) {
  console.log(fruit);
}

Array methods

Arrays come with built-in methods — functions that belong to the array. The four you will use most are push (add to the end), pop (remove from the end), indexOf (find the position of a value) and join (glue the items into one string):

let tasks = ["Learn HTML", "Learn CSS"];
tasks.push("Learn JavaScript");
console.log(tasks);  // ["Learn HTML", "Learn CSS", "Learn JavaScript"]
let last = tasks.pop();
console.log(last);   // "Learn JavaScript"
console.log(tasks.indexOf("Learn CSS"));  // 1
console.log(tasks.join(", "));  // "Learn HTML, Learn CSS"

There are many more methods — filter, map and forEach are the next ones to learn — but these four carry most real programs. The to-do app in Lesson 18 is built almost entirely from push, filter and join.

Objects: labelled values

An array is a list in order. An object is a set of labelled values — each value has a name, called a key. Objects describe one thing with several properties:

let student = {
  name: "Usman",
  age: 20,
  city: "Lahore",
  isEnrolled: true
};
console.log(student.name);  // "Usman"
console.log(student.city);  // "Lahore"
student.age = 21;           // change a property

You read a property with dot notation — student.name. You can add a new property the same way, by assigning to a key that does not exist yet. Objects and arrays are the two shapes almost all data takes in JavaScript: a list of things (array) where each thing has named fields (object).

Arrays of objects

Put them together and you can describe real data. A list of students, where each student is an object:

let students = [
  { name: "Usman", age: 20, city: "Lahore" },
  { name: "Ahmad", age: 21, city: "Karachi" },
  { name: "Sara", age: 19, city: "Islamabad" }
];

for (let s of students) {
  console.log(s.name + " lives in " + s.city);
}

This pattern — an array of objects, looped over to build a page — is behind almost every list on the internet: products in a shop, posts in a feed, messages in a chat. Learn it well, because the final project uses exactly this shape to store its tasks.
