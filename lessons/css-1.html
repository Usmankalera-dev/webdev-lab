What CSS does

CSS stands for Cascading Style Sheets. If HTML is the structure of a page — the walls and rooms of the house — CSS is the paint, the furniture and the lighting. It decides colours, sizes, spacing, fonts and layout. Without CSS, every page on the internet would look like a plain text document. With CSS, the same HTML can look like a blog, a shop, or a dashboard.

HTML says what things are. CSS says how they look. That separation is the whole idea: you can change the design of an entire website by editing one CSS file, without touching the HTML at all. That is why professional websites keep their CSS in a separate file.

Three ways to add CSS

There are three ways to attach CSS to a page. Inline styles live inside a tag's style attribute. They work, but only for one element, and they make the HTML messy — avoid them except for quick tests:

<p style="color: red;">This text is red.</p>

Internal CSS lives in a <style> tag inside the page's <head>. It styles only that one page, which is handy for a single-page test:

<head>
  <style>
    p { color: blue; }
  </style>
</head>

External CSS lives in its own file, usually called styles.css, and the page links to it. This is the right way for a real website — one file styles every page, so changing one line changes the whole site:

<head>
  <link rel="stylesheet" href="styles.css">
</head>

This website uses external CSS. Every page you have opened so far loads the same styles.css file. When you change the theme from dark to light, one file does all the work.

Selectors and rules

A CSS rule has two parts: a selector that picks which elements to style, and a declaration block in curly braces that says how to style them. Each declaration is a property and a value, separated by a colon, ending with a semicolon:

h1 {
  color: darkblue;
  font-size: 32px;
}

That rule says: every <h1> on the page should be dark blue and 32 pixels tall. There are three basic selectors. An element selector (h1, p) styles every element of that type. A class selector starts with a dot (.warning) and styles every element with class="warning" — the same class can be reused on many elements. An ID selector starts with a hash (#main-title) and styles the one element with that id:

p { color: #333; }              /* every paragraph */
.warning { color: red; }      /* every element with class="warning" */
#main-title { color: navy; }  /* the one element with id="main-title" */

Use classes for anything you will repeat, and ids for one unique thing on the page. And remember: CSS ignores extra spaces and line breaks, so format your rules neatly — future you will be grateful.

Your first styled page

Let us put it together. This small page has no CSS file yet — the style is internal, so you can try it in one file:

<!DOCTYPE html>
<html>
<head>
  <title>My Styled Page</title>
  <style>
    body { background-color: #f9fafb; }
    h1 { color: #d97706; }
    p { color: #333333; font-size: 18px; }
    .highlight { background-color: #fef3c7; }
  </style>
</head>
<body>
  <h1>Hello, styled world!</h1>
  <p class="highlight">This paragraph has a yellow
  background because of its class.</p>
</body>
</html>

Change one value — the heading colour, the font size — save, and refresh. That instant feedback is the fun of CSS: you see your change the moment you save.

Exercise — Style your personal page

Create a file called styles.css next to your personal page, and link it with a link tag in the head. In the CSS file, set the body background to a light colour, make the h1 dark blue and larger, and give one paragraph a class called highlight with a yellow background. Refresh your page — the styles should apply without changing any HTML except the one link tag.
