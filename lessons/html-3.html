Images: the img tag

Text alone makes a dull page. Images make it come alive. The <img> tag adds a picture to your page. It is an empty element — it has no closing tag — and it needs two attributes to do its job:

<img src="cat.jpg" alt="A grey cat sleeping in the sun">

The src attribute (short for "source") says where the image file is. It can be a file in the same folder as your page (cat.jpg), a file in another folder (images/cat.jpg), or a full web address (https://example.com/cat.jpg). The alt attribute (short for "alternative text") describes the picture in words.

The alt text matters more than beginners think. If the image fails to load, the browser shows the alt text instead. Screen readers read it out loud for blind visitors. Search engines use it to understand what the picture shows. Every image needs an alt attribute. If an image is purely decorative, use an empty alt (alt="") so screen readers skip it — but never leave the attribute out completely.

You can also control the size with the width and height attributes, measured in pixels:

<img src="team.jpg" alt="Our team at the Lahore office"
     width="600" height="400">

Setting both width and height also stops the page from jumping around while the image loads, which makes your site feel faster. In the CSS module you will learn a better way to size images, but these attributes are a good start.

Lists: ul, ol and li

Lists are everywhere on the web: navigation menus, shopping lists, steps in a recipe, features on a pricing page. HTML has two kinds.

An unordered list (<ul>) is for items with no special order. The browser shows a bullet point in front of each item:

<ul>
  <li>Fresh bread</li>
  <li>Chocolate cake</li>
  <li>Butter biscuits</li>
</ul>

An ordered list (<ol>) is for items where the order matters — steps, rankings, instructions. The browser numbers each item automatically:

<ol>
  <li>Mix the flour and sugar.</li>
  <li>Add the eggs and milk.</li>
  <li>Bake for 30 minutes.</li>
</ol>

Every item in both kinds of list uses the <li> tag. You can also nest lists — put a whole <ul> inside one <li> — to make a list inside a list. That is how multi-level navigation menus are built.

Tables: rows and cells

Tables are for data that belongs in rows and columns: a class timetable, a price list, match scores. A table is built from three tags. <table> is the whole table. <tr> is a table row. Inside each row, <th> is a header cell (bold, centred) and <td> is a normal data cell:

<table>
  <tr>
    <th>Day</th>
    <th>Class</th>
    <th>Time</th>
  </tr>
  <tr>
    <td>Monday</td>
    <td>HTML Basics</td>
    <td>9:00 AM</td>
  </tr>
  <tr>
    <td>Wednesday</td>
    <td>CSS Basics</td>
    <td>9:00 AM</td>
  </tr>
</table>

Read the code like a grid: each <tr> is one horizontal line, and the cells inside it are the columns. The first row uses <th> because it is the header — Day, Class, Time. Every row after that uses <td>.

One warning: tables are only for tabular data. In the early days of the web, people used tables to lay out whole pages, and that was a bad idea — it makes pages slow, hard to change and impossible to read on a phone. For layout, use CSS (you will learn Flexbox in the CSS module). For data, use tables.

Putting it together

Images, lists and tables often appear together on one page. A shop page might show a product image, a list of features, and a table of prices. You now know all three tags, so you can build that page already.

Exercise — Your favourites page

Add a new section to your personal page from Lesson 2: an <h2> called "My Favourite Foods", an unordered list of three foods, an <h2> called "My Weekly Schedule", and a table with three rows (Day, Activity, Time). Then add one image — any picture saved in the same folder as your page — with a proper alt description. Save, refresh, and check that everything shows correctly. If the image does not appear, check the file name in src — one wrong letter is the most common cause.
