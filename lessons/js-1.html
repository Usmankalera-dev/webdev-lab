What JavaScript does

HTML builds the structure of a page. CSS makes it look good. JavaScript makes it do things. It is the programming language of the web: it reacts to clicks, checks form inputs, loads new data without reloading the page, and changes what is on the screen while the visitor watches.

Every interactive thing you have used on the web — a like button, a shopping cart, a live search box, a photo slider — is JavaScript. It runs in the visitor's browser, on their device, the moment the page loads. Unlike HTML and CSS, JavaScript is a real programming language: it has variables, conditions, loops and functions, and you can build almost anything with it.

Adding JavaScript to a page

JavaScript lives inside <script> tags. You can put them in the <head>, but the usual place is at the end of the <body> — that way the HTML loads first, and the script runs after the page exists:

<body>
  <h1>Hello</h1>
  <script>
    alert("Hello from JavaScript!");
  </script>
</body>

For a real website, the script goes in its own file, just like CSS. A file called script.js is linked with a src attribute:

<script src="script.js"></script>

This website does exactly that — every page you have opened loads the same script.js, which powers the theme toggle, the progress bar and the quizzes. One script file, shared by the whole site, just like the stylesheet.

Your first line: console.log

The simplest JavaScript command is console.log(). It prints a message to the browser's console — a panel for developers. Open it with F12 (or Ctrl+Shift+J on Windows, Cmd+Option+J on Mac) and click the Console tab:

console.log("Hello, world!");
console.log(2 + 3);

The first line prints the text. The second prints 5, because JavaScript can do maths. The console is where you will test ideas and find mistakes for the rest of this module — error messages appear there, with the line number where the problem is. When something does not work and the page looks fine, the console is the first place to look.

One more thing: every JavaScript statement usually ends with a semicolon. JavaScript will often guess where a statement ends without one, but relying on guessing causes strange bugs. End your statements with semicolons from day one.

Making a button do something

Here is the classic first program in JavaScript: a button that counts clicks. The HTML gives the button an id, and the script finds it and listens for clicks:

<button id="countBtn">Clicked 0 times</button>

<script>
  var count = 0;
  var button = document.getElementById("countBtn");
  button.addEventListener("click", function () {
    count = count + 1;
    button.textContent = "Clicked " + count + " times";
  });
</script>

Do not worry if every line is not clear yet — the next three lessons explain variables, functions and events one by one. The point is the shape: HTML provides the button, JavaScript finds it, listens, and changes it. That pattern — find, listen, change — is the heart of everything you will build in this module.

Exercise — A greeting button

Make a page with a button that says 'Say hello'. Add a script at the end of the body that finds the button by its id and, when clicked, shows an alert saying 'Hello, and welcome to my page!'. Open the page, open the console with F12, and add a console.log line that prints 'Button clicked' — watch it appear in the console every time you click.
