Colours in CSS

CSS gives you three ways to write a colour. Colour names are the simplest — red, darkblue, gold — but there are only 140 of them, and "lightblue" may not be the exact blue you want. Hex codes are the professional standard: a hash followed by six digits, two each for red, green and blue. #ff0000 is pure red, #000000 is black, #ffffff is white, and #a88462 is the tan colour this website uses:

h1 { color: #6b4a2e; }          /* brown heading */
p  { color: #333333; }          /* dark grey text */
body { background-color: #f9fafb; }  /* very light grey */

RGB writes the same three numbers in decimal: rgb(255, 0, 0) is the same red as #ff0000. RGBA adds a fourth number for transparency — rgba(0, 0, 0, 0.5) is black at half strength, so whatever is behind it shows through. Use color for text and background-color for the fill behind it. One rule of design: text must be easy to read. Dark text on a light background, or light text on a dark background — never light grey on white.

Fonts

The font-family property picks the typeface. You do not name one font — you name a list, called a font stack, from your first choice to a safe fallback. If the visitor's device does not have your first font, it tries the next one:

body {
  font-family: Georgia, "Times New Roman", serif;
}
h1 {
  font-family: Arial, Helvetica, sans-serif;
}

There are five generic families every device understands: serif (letters with little feet, like Times New Roman — good for long reading), sans-serif (clean letters without feet, like Arial — good for screens), monospace (every letter the same width, like Courier — for code), cursive and fantasy. Always end your stack with a generic family, so the text never falls back to a random font.

You can also load web fonts from services like Google Fonts, which gives you thousands of free fonts with one link tag. That is how most modern sites get their distinctive look. For now, system fonts are enough — learn the properties first, then explore fonts later.

Text size and weight

Size is set with font-size. Pixels (px) are exact and easy: 16px is the browser default for body text. But pixels do not scale when a visitor zooms or changes their settings, so professionals often use rem — one rem equals the root font size (usually 16px), so 1.5rem is 24px and it grows if the visitor makes their text bigger:

h1 { font-size: 2.5rem; }   /* about 40px */
p  { font-size: 1rem; }     /* 16px, the default */
small { font-size: 0.85rem; }

font-weight controls boldness: 400 is normal, 700 is bold, and 300 is light. line-height controls the space between lines — 1.6 (no unit, a multiple of the font size) makes long paragraphs much easier to read than the cramped default of about 1.2.

Text alignment and style

Three more properties finish the basics. text-align moves text left, right, centre or justified (left is the default for English, and the easiest to read — centre is for headings and short lines, never for long paragraphs). text-decoration adds or removes underlines — links are underlined by default, and text-decoration: none is how navigation links lose the line. letter-spacing adds space between letters, which makes small capital-style headings look sharp:

h2 {
  text-align: center;
  letter-spacing: 1px;
}
a { text-decoration: none; }
a:hover { text-decoration: underline; }

That last rule uses a pseudo-class: :hover means "when the mouse is over this link". Pseudo-classes let you style an element in a particular state — :hover, :focus (when a field is selected), :first-child. You will use :hover constantly, starting with the mini projects.

Exercise — A readable article page

Make a small article page with one h1, two h2 headings and three paragraphs. Style it: body font Georgia, serif; h1 dark blue at 2.5rem, centred; paragraphs at 1rem with line-height 1.7; links with no underline until hover. Then change the h1 colour to a hex code of your choice and watch it update.
