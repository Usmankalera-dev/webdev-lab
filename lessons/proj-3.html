Mini Project 3: Navbar

The navigation bar is the part of a website visitors use most, and it is also the part beginners get wrong most often. In this project you build a proper navbar: logo on the left, links on the right, a sticky position so it stays visible while scrolling, and a layout that still works on a phone — using Flexbox from Lesson 9.

Step 1 — The HTML

A navbar is a <header> with a logo link and a <nav> holding the page links:

<header class="navbar">
  <a class="logo" href="#">My Bakery</a>
  <nav>
    <a href="#">Home</a>
    <a href="#">Menu</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
  </nav>
</header>

Step 2 — Flexbox layout

The header is a flex container. justify-content: space-between pushes the logo to the left and the nav to the right, and align-items: center lines them up vertically. The nav is itself a flex container, so its links sit in a row with a gap:

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 12px 20px;
  background: #111827;
}
.navbar nav { display: flex; gap: 20px; }
.navbar a { color: #f9fafb; text-decoration: none; }

Step 3 — Style the logo and links

Make the logo stand out — bigger, bolder, amber — and give the links a hover effect so visitors can see what they are about to click:

.navbar .logo {
  font-size: 1.3rem;
  font-weight: 800;
  color: #f59e0b;
}
.navbar nav a { padding: 8px 10px; border-radius: 8px; }
.navbar nav a:hover { background: #374151; }

Step 4 — Make it sticky

A sticky navbar stays at the top of the screen while the visitor scrolls, so the navigation is always one tap away. One line does it:

.navbar {
  position: sticky;
  top: 0;
  z-index: 50;
}

position: sticky means "scroll normally, but stop at the top of the screen and stay there". top: 0 says where it stops. z-index: 50 makes sure the bar floats above the page content instead of sliding underneath it. This website's own header uses exactly these three lines.

Step 5 — Mobile layout

On a phone, four links plus a logo may not fit in one row. Add a media query that lets the bar wrap, and shrinks the gaps:

@media (max-width: 600px) {
  .navbar { flex-wrap: wrap; gap: 8px; }
  .navbar nav { gap: 8px; }
  .navbar nav a { padding: 6px 8px; }
}

With flex-wrap: wrap, the links drop onto a second line instead of squeezing or overflowing. Test it by shrinking your browser window: the bar should stay readable at every size, with no horizontal scrolling.
