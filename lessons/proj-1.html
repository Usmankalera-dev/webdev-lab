Mini Project 1: Profile Card

A profile card is the smallest real website: a photo, a name, a short line about the person, and links. You have seen them on team pages, social profiles and portfolios. In this project you build one from scratch, using the HTML and CSS from the first two modules. By the end you will have a card you can reuse on your own portfolio.

Step 1 — The HTML structure

A card is a <div> with a photo, a heading, a paragraph and some links inside. The photo uses a placeholder image from the internet here — replace it with your own photo later:

<div class="card">
  <img src="https://via.placeholder.com/150" alt="Photo of Usman">
  <h2>Muhammad Usman</h2>
  <p class="role">AI Engineer & Creator</p>
  <p>Building AI video ads and websites in Lahore.</p>
  <a href="https://github.com/Usmankalera-dev">GitHub</a>
  <a href="https://usmankalera-dev.github.io/portfolio/">Portfolio</a>
</div>

Step 2 — Card styling

Now make it look like a card: a white background on a light page, padding inside, rounded corners, and a soft shadow. The box-shadow property takes four values — how far right, how far down, how blurry, and the colour:

.card {
  width: 320px;
  margin: 40px auto;
  padding: 24px;
  background: #ffffff;
  border-radius: 16px;
  box-shadow: 0 4px 16px rgba(0, 0, 0, 0.15);
  text-align: center;
}

margin: 40px auto centres the card (from the Box Model lesson), and text-align: center centres everything inside it.

Step 3 — A round photo

Profile photos are usually round. A square image becomes a circle with two rules: make it square, then set border-radius: 50%:

.card img {
  width: 120px;
  height: 120px;
  border-radius: 50%;
  object-fit: cover;
  border: 3px solid #f59e0b;
}

object-fit: cover crops the photo to fill the square instead of stretching it, so faces never look squashed. The amber border matches this website's accent colour.

Step 4 — Style the text and links

Finish the inside of the card. The role line gets a muted colour and no top margin, and the links become small amber buttons:

.role {
  color: #6b7280;
  margin-top: -8px;
}
.card a {
  display: inline-block;
  margin: 4px;
  padding: 8px 16px;
  background: #f59e0b;
  color: #111827;
  text-decoration: none;
  border-radius: 8px;
  font-weight: bold;
}
.card a:hover { background: #d97706; }

Step 5 — Make it responsive

On a phone, a 320px card fits — but only just. Change the width to 90% with a max-width, so it fills small screens and stops growing on big ones:

.card {
  width: 90%;
  max-width: 320px;
}

That is the whole project: structure, card styling, a round photo, buttons, and one responsive rule. Save it, open it on your phone, and you have a real profile card to show people.
