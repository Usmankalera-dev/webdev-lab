What is the DOM?

When the browser loads a page, it turns the HTML into a tree of objects called the DOM — the Document Object Model. Every tag becomes an object: the <h1> is an object, each paragraph is an object, each button is an object. JavaScript can reach into this tree, find any element, read it, change it, or delete it — and the page updates instantly, without reloading.

That is the whole trick of interactive websites. HTML builds the tree, JavaScript edits it. Everything in this lesson is about finding elements and changing them.

Finding elements

There are two ways to find an element. getElementById finds the one element with a given id — fast and exact, because ids are unique:

let title = document.getElementById("main-title");

querySelector finds the first element that matches a CSS selector — an id, a class, a tag, or anything more specific:

let firstButton = document.querySelector("button");
let menu = document.querySelector(".menu");
let intro = document.querySelector("#intro");

And querySelectorAll finds every matching element and returns them as a list you can loop over. If nothing matches, getElementById and querySelector return null — and trying to change null throws an error. When your script says "cannot read properties of null", it almost always means the id in your JavaScript does not match the id in your HTML. Check the spelling first.

Changing content and style

Once you have an element, you can change it. textContent changes the text inside it. style changes its CSS, one property at a time — note that CSS names with hyphens become camelCase in JavaScript (background-color becomes backgroundColor):

let heading = document.getElementById("main-title");
heading.textContent = "Welcome to my page!";
heading.style.color = "darkblue";
heading.style.fontSize = "32px";

You can also change classes instead of single styles, which is cleaner when several properties change at once. classList.add("hidden") adds a class, classList.remove("hidden") takes it away, and classList.toggle("hidden") switches it on or off. This is how the dark-mode button on this website works — it toggles a class on the whole page.

One warning: innerHTML lets you set HTML inside an element, but it is dangerous with text from users — a visitor could inject their own HTML or scripts. For your own fixed text it is fine; for anything a user typed, use textContent instead.

Listening for events

An event is something that happens on the page: a click, a key press, a form being submitted, the page finishing loading. addEventListener tells the browser: "when this event happens on this element, run this function":

let button = document.getElementById("likeBtn");
let count = 0;
button.addEventListener("click", function () {
  count++;
  button.textContent = "Likes: " + count;
});

Notice the function has no name and no parentheses after it — you are handing the function to the browser, and the browser calls it later, every time the button is clicked. The most common events are click, input (when a field's value changes), submit (when a form is sent) and keydown. With find, listen and change, you can build almost any interaction on the web.

Exercise — A theme switcher

Make a page with a heading, a paragraph and a button that says 'Dark mode'. Add a script: when the button is clicked, toggle a class called dark on the body, and change the button text to 'Light mode' (and back). In your CSS, define body.dark with a dark background and light text. This is the same idea as the theme toggle on this website.
