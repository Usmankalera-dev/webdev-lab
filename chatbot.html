AI Chatbot

Ask anything about HTML, CSS and JavaScript — in English, Urdu or Roman Urdu. No key needed: the chatbot answers with GPT-6 Astra or Luna.

How this chatbot works

  1. Ask anything about web development. Unlike the AI Tutor (which answers only from the 23 lessons), this chatbot answers general HTML, CSS and JavaScript questions.
  2. Pick a model. GPT-6 Astra answers first. If Astra does not answer, the chatbot tries GPT-6 Luna automatically.
  3. No key needed. The key is saved in the site's database — students never see it and never need their own key. Your chat stays in this browser only.

If the chatbot shows an error, the AI endpoint is blocking the request right now — try again later, or ask the AI Tutor, which answers from the lessons without any key.
